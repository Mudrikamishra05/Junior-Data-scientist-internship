## 🌾 Project Overview: Crop Yield Prediction

The project uses an agricultural dataset containing **1,000,000 observations and 10 columns**.

The target variable is `Yield_tons_per_hectare`, which represents crop yield in tons per hectare.

### Dataset Variables

| Variable                 | Description                               |
| ------------------------ | ----------------------------------------- |
| `Region`                 | Geographical region                       |
| `Soil_Type`              | Type of soil                              |
| `Crop`                   | Crop category                             |
| `Rainfall_mm`            | Rainfall in millimetres                   |
| `Temperature_Celsius`    | Temperature in degrees Celsius            |
| `Fertilizer_Used`        | Indicates whether fertilizer was used     |
| `Irrigation_Used`        | Indicates whether irrigation was used     |
| `Weather_Condition`      | Recorded weather condition                |
| `Days_to_Harvest`        | Number of days until harvest              |
| `Yield_tons_per_hectare` | Target variable for crop yield prediction |

The project explores how these variables can be analyzed to understand agricultural productivity and support crop yield prediction.

## 📊 Model Evaluation

Regression models can be assessed using the following metrics:

* **Mean Absolute Error (MAE):** Measures the average absolute prediction error.
* **Root Mean Squared Error (RMSE):** Measures prediction error while giving greater weight to larger errors.
* **R-squared (R²):** Indicates how much variation in the target variable is explained by the model.

These metrics help compare models and understand their predictive performance.
